# Pilot Proposal

## Objective

Validate whether BreatheAtrium can reduce atrium heat build-up, improve comfort hours, and lower cooling burden in a real tropical atrium without claiming full HVAC replacement.

## Duration

Pilot target: 90 days.

## Measurement Plan

- Weather.
- Occupied-zone temperature.
- Roof-layer temperature.
- Relative humidity.
- CO2.
- Damper position.
- Airflow proxy.
- HVAC runtime proxy.
- Occupant feedback.

## Success Criteria

Use pilot target language until measured:

- Improved comfort hours.
- Reduced roof-layer heat build-up.
- Lower cooling-burden proxy.
- Usable BMS handoff modes.
- Facilities team acceptance.
